```ts
  return forbiddenIn(text, source, BRIEFING_BANNED);
}
```

- `source` = `sourceText(snapshot)`: 스냅숏 뉴스의 `title`·`summary` 와 공시 `title` 을 줄바꿈으로 이은 글(`null` 은 빈 글).
- **출처 예외는 `forbiddenIn` 규칙 그대로**입니다: 걸린 말 앞뒤로 **빈칸 없이 붙은 글자**를 한 자씩 늘려 가며 출처에 있는지 보고, 2자 이상 늘어나야 넘어갑니다. 줄 전체가 출처에 있다고 넘어가지 **않습니다**. 예:
  - 출처 `주식매수선택권부여에관한신고`, 줄 `- 주식매수선택권부여에관한신고 (공시)` → `null` (공시 제목 속 긴 말).
  - 출처 `증권가, SK하이닉스 목표가 상향`, 줄 `- 증권가 목표가 상향 (한경)` → `"목표가"` (따로 쓰인 말이라 걸림).
  - 출처 `관세 우려에 반도체 약세`, 줄 `- 관세 우려에 반도체 약세 (연합뉴스)` → `"우려"` (줄째로 같아도 걸림).
- 내보낼 함수: `sourceText(s)`, `findBanned(text, source)`, `codeSummaryLine(quote)`, `countLine(s)`, `safeSummary(s, modelText)` (= `${codeSummaryLine(s.quote)}\n${둘째 줄}`), `cleanDetail(detail, source): { text: string; dropped: number }`, `cleanPrevious(summary, source): string`, `unknownNumbers(detail, known)`. `s` 는 `Pick<BriefingSnapshot, "quote" | "news" | "disclosures">`(`services/collector.ts:44`).

## 2. Codex 환경 설정 (Environment settings)

- 저장소: `ssw11380-sys/disney-adventure-cruise-guide`, 기본 브랜치 `main`.
- 이미지: 기본(universal). 패키지 버전에서 **Node.js 22** 를 고릅니다(CI 와 같음).
- 환경 변수: `TZ` = `Asia/Seoul` (테스트가 한국 시간 기준). **비밀값(Secrets)은 넣지 않습니다** — 테스트는 키 없이 가짜 데이터로 돕니다.
- 에이전트 인터넷: 끔(설치는 설정 스크립트에서 끝남).
- 설정 스크립트(Setup script):

```bash
#!/usr/bin/env bash
set -euo pipefail
export TZ=Asia/Seoul
node -v
cd stock-briefing/backend
npm ci --no-audit --no-fund
cd ../app
npm ci --no-audit --no-fund
```

- 유지 스크립트(Maintenance script): 비워 둡니다.
- Postgres 는 없습니다. `TEST_PG_URL` 이 없으면 Postgres 테스트는 건너뛰는 것이 정상입니다(CI 가 Postgres 로 따로 돌림). `REQUIRE_PG` 는 설정하지 않습니다.

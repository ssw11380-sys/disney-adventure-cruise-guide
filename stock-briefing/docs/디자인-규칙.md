# 디자인 규칙 (3-20)

색·간격·글자 크기는 `app/src/tokens.ts` 한 곳에 있습니다. 화면 코드는 이 토큰만 씁니다.
숫자나 hex를 직접 쓰면 `npm run lint`가 막습니다(`eslint.config.js`의 `designRules`).
`app/test/tokens.test.ts`는 대비와 색 차이를 검사합니다.

## 색

| 역할 | 토큰 | 규칙 |
|---|---|---|
| 상승 / 하락 | `t.up` / `t.down` | 한국 관례대로 상승 빨강, 하락 파랑입니다. **등락에만** 씁니다. |
| 칠한 등락 칸 | `t.upFill` / `t.downFill` + `t.onFill` | 흰 글자가 4.5:1 이상 읽히는 진한 색입니다(등락률 상자). |
| 강조(선택·링크·버튼) | `t.accent` / `t.accentInk` | 청록입니다. 파랑을 쓰면 하락으로 읽혀서 등락색과 ΔE2000 20 이상 떨어뜨렸습니다. |
| 실시간·장중 | `t.live` | 초록 점과 글자입니다. 빨강을 쓰면 상승으로 읽히므로 `t.up`을 쓰지 않습니다. |
| 내 평단·보유 | `t.gold` | |
| 글자 | `t.ink` > `t.sub` > `t.muted` | 본문 → 보조 → 설명·시각 순입니다. 세 단계 모두 바탕 3종에서 4.5:1 이상입니다. |
| 경고 / 오류 | `t.warn` / `t.danger` | 오류는 다크 주황·라이트 자주 — 빨강이면 상승으로 읽혀서 등락색과 ΔE2000 20 이상 |
| 차트 보조선 | `t.chart.ma[기간]`, `rsi`, `macd`, `signal`, `band` | 등락색과 ΔE2000 20 이상, 바탕에서 3:1 이상, 가격 영역에 같이 그리는 선(이동평균·볼린저·평단)끼리 ΔE2000 15 이상입니다. 선 색은 글자 대비를 보장하지 않으므로 범례 글자는 흐린 글자색으로 쓰고 색은 네모에만 칠합니다. |
| 모달 뒤 | `t.scrim` | |

- 라이트·다크 두 테마 모두 같은 규칙을 지킵니다.
- 색을 새로 넣을 때는 `tokens.ts`의 두 테마에 같이 넣고 `tokens.test.ts`를 통과시킵니다.

## 간격

`space` 7단계를 씁니다: `xxs 2 · xs 4 · s 6 · sm 8 · md 12 · lg 14 · xl 20`. 0은 직접 써도 됩니다.
카드 안 여백은 `lg`, 줄 사이는 `sm`, 글자와 아이콘 사이는 `xs`를 기본으로 합니다.

## 글자 크기

`font` 6단계를 씁니다: `hero 28`(큰 가격·총평가) · `title 20` · `h2 16`(카드 제목·헤더) · `body 14` · `small 12` · `tiny 11`(차트 축·배지·설명).
숫자는 `fontVariant: ["tabular-nums"]`로 자릿수를 맞춥니다.

## 아이콘·기호

- 아이콘은 Ionicons만 씁니다(◀▶▾■●✓ 같은 글자 기호는 lint가 막습니다).
- 가격 옆 `▲2,500` / `▼0.30` 같은 등락 표기는 증권사 관례라 글자로 둡니다.
- 스위치는 `components/ui`의 `Toggle` 하나만 씁니다.

## 예외

홈 화면 위젯은 `app/src/widgets/palette.ts`에 색과 글자 크기를 따로 둡니다. 이유는 두 가지입니다.
- 안드로이드 RemoteViews로 그려서 앱 테마와 아이콘 글꼴을 쓸 수 없습니다.
- 칸이 작아서 앱보다 작은 글자 단계가 필요합니다.

위젯 규칙 (3-23):
- **색은 `palette.ts` 한 곳에서만** 가져옵니다. `palette.ts`는 `tokens.ts`의 라이트·다크 값을 그대로 써서 두 벌(`WIDGET_PALETTES.light`·`.dark`)을 만듭니다. 위젯만의 색은 두지 않습니다.
- 위젯은 **라이트·다크 두 벌을 함께** 그립니다(`widgets/render.tsx`의 `renderBoth`). 안드로이드가 시스템 테마에 맞는 쪽을 보여 주므로 테마를 바꿔도 서버를 다시 부르지 않습니다. 오류 화면도 두 벌입니다.
- 위젯 바탕 위 모든 글자색은 대비 4.5 이상입니다(`app/test/widgetRender.test.tsx`).
- **숫자는 자르지 않습니다**(… 줄임 금지). 칸이 모자라면 `widgets/layout.ts`가 글자를 줄이거나 덜 중요한 칸을 뺍니다. 이름·브리핑 문장만 줄일 수 있습니다. 2x1·4x2·4x4 × 글자 100·130%를 `app/test/widgetLayout.test.ts`가 검사합니다.
- **높이도 넘치지 않게** 합니다. `layout.ts`가 세로 합(머리 줄 48 + 합계 줄 + 지수 줄 + 메모 + 아래 여백)을 어림합니다.
  - 잔고 목록(`ListWidget`)은 첫 줄이 보일 자리가 있을 때만 넣습니다. 높이 0인 목록은 라이브러리가 예외를 던지고, 그러면 위젯이 아예 갱신되지 않습니다.
  - 자리가 모자라면 목록 > 메모 > 손익 전환 칸 순으로 지킵니다. 전환 칸을 먼저 빼고(누적만), 그다음 메모를 머리 줄의 '갱신 실패'로 옮기고, 그래도 없으면 목록을 뺍니다.
  - 브리핑 위젯의 고지 한 줄은 늘 들어갑니다. 4x2 최소 크기에서는 종목을 '이름 · 요약' 한 줄로 보여 줍니다.
- 누르는 칸(↻·손익 전환)은 48×48dp 이상(`WIDGET_TOUCH`)입니다.
  - 그래서 머리 줄은 48dp입니다(예전 약 25dp).
  - 손익 전환 칸이 있는 합계 줄은 위아래 여백 없이 48dp입니다(없으면 여백 포함 약 32~50dp). 그만큼 목록이 덜 보이지만 한 줄 미만(최대 약 16dp)입니다.
  - 4x2 최소 크기(110dp)에서는 목록 자리가 없어 머리 줄과 합계만 보입니다.
  - 자리가 모자라 전환 칸을 뺀 크기에서는 손익을 눌러도 앱이 열립니다(`docs/기능-플래그.md`의 알려진 한계).
- 글자 폭 어림은 실제 글꼴보다 넓어야 합니다. `app/test/widgetLayout.test.ts`가 보통 굵기(Roboto)와 굵은 글자(Roboto Bold·맑은 고딕 Bold를 잰 값)를 모두 견줍니다. 삼성 기본 글꼴(SamsungOne)과 Roboto Black(굵기 800)은 잰 값이 없어 실기기에서 확인합니다(3-26).
- 알려진 한계 — 글자 크기 배율: 위젯은 그리는 순간의 시스템 글자 크기 배율(`PixelRatio.getFontScale()`)로 배치를 고릅니다. 그런데 이 값은 앱 화면이 다시 보일 때만 새로 읽힙니다(React Native가 값을 저장해 둠). 설정에서 글자 크기를 바꾸고 앱을 열지 않으면, 위젯 갱신이 옛 배율로 배치를 고를 수 있습니다. 글자는 새 배율로 그려지므로 숫자가 칸을 넘을 수 있습니다. JS만으로는 고칠 수 없고(네이티브 추가 필요), 앱을 한 번 열면 맞춰집니다. 실기기 점검(3-26)에서 확인합니다.
- 누르는 칸에는 화면 읽기 이름표(`accessibilityLabel`)를 답니다. 잔고 행은 '이름 가격 등락률'(예: "삼성전자 72,000원 1.50% 상승"), 위젯 전체가 한 칸인 자산 위젯은 가려진 값까지 한 문장으로 읽습니다.
- 라이브러리가 트리를 만들 때 `null`을 돌려주는 컴포넌트와 Fragment를 다루지 못합니다. 조건부 칸은 부모에서 `조건 ? <칸 /> : null`로 넣습니다.

## 큰 글씨·화면 읽기 (3-22)

`app/test/a11y.test.ts`가 아래 규칙을 검사합니다.

### 누르는 크기

- 누르는 요소는 **보이는 높이 + hitSlop이 44 이상**입니다(`touch.min`).
- 작은 버튼은 `hitSlop={slopFor(보이는 높이, 좌우)}`로 넓힙니다. 숫자를 직접 쓰지 않습니다(`hitSlop={8}` 금지).
- 줄 전체가 버튼이면 `minHeight: touch.min`을 줍니다.
- 좌우 hitSlop은 이웃 버튼과 겹치지 않게 간격의 절반 이하로 둡니다.

### 화면 읽기 이름표

- `Pressable`에는 `accessibilityRole`과 `accessibilityLabel`을 **둘 다** 줍니다.
- 입력칸(`TextInput`)과 스위치(`Toggle`)는 이름표가 필수입니다. 자리 표시 글자는 이름이 되지 못합니다.
- 기호는 말로 바꿉니다(`lib/a11y.ts`): `+2.86%` → "2.86% 상승", `$230.10` → "230.10달러", `-1,500원` 손익 → "1,500원 손실".
- 한 줄에 숫자가 여럿인 곳(잔고 한 줄, 계좌 요약)은 **한 문장**으로 읽게 묶습니다.
- 버튼이 다른 버튼을 감싸면 안에 있는 버튼을 화면 읽기로 고를 수 없습니다. 모달 배경은 창을 감싸지 말고 뒤에 따로 깝니다.

### 글자 확대

- 본문은 시스템 글자 크기를 그대로 따릅니다(200%까지).
- 확대 상한은 `fontCap`에 모아 둡니다.
  - 고정 폭 열이 있는 종목 줄·표: `fontCap.row` 140%
  - 탭 바·화면 머리: `fontCap.chrome` 150%. 높이는 `useFontScale()`로 글자에 맞춰 늘립니다.
- 가격·손익 같은 숫자 칸은 말줄임(…) 대신 `adjustsFontSizeToFit`로 줄여서 한 줄에 다 보입니다.
- 종목명·보조 줄은 글자를 키웠을 때만 두 줄까지 허용합니다(100%는 한 줄 그대로).
- 높이가 고정인 목록(발견·테마)은 `useLineH()`·`useThemeRowH()`로 높이를 정하고, `getItemLayout`도 같은 값을 씁니다.

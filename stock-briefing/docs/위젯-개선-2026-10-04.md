## 검증 기록

- 위젯 금액 링크: 변경 전 새 재현 검사 실패(토스 계좌 표시), 변경 후 같은 검사 통과. 수동으로 토스 탭을 선택한 뒤 다시 위젯 링크를 여는 경우도 포함.
- 그 밖의 자동 검사·실제 기기 확인 결과는 통합 검증 후 아래에 확정 기록한다. 아직 실행하지 않은 항목은 통과로 간주하지 않는다.

## 속도·품질 보호

- 분석 모델·프롬프트·입력 자료·분석 단계·보고서 출력 분량을 변경하지 않는다.
- 위젯 개인 설정 변경은 이미 받은 자료를 다시 그리며, AI 생성이나 시세 재조회가 필요하지 않다.
- 기존 보고서 3개는 내용 자체를 보관하지 않고 변경 전후 응답 해시로 보존 여부를 대조한다. 생성 품질 전반을 입증하는 검사는 아니다.
- 변경 전 운영 위젯 조회: Windows PC→운영 서버, 순차 3회. 첫 조회 200/618ms, ETag 조건부 304/167ms·150ms. 서버 내부 캐시 상태는 미확인. 실제 Android 지연이나 AI 생성 시간 측정이 아니다.
- 소표본·다른 시각의 통신 결과로 개선율을 계산하지 않는다. 운영 자료를 바꾸거나 유료 AI 보고서를 반복 생성하지 않는다.

## 배포·미검증 상태

현재 문서는 구현 중 기록이다. 최종 테스트·게시·운영 응답·기기 적용을 마친 뒤 해당 근거를 덧붙인다.

위젯 자동 갱신은 Android의 예약 실행·배터리 상태에 영향을 받는다. 이번 범위는 표시와 조작의 정확성을 개선하며 지속적인 실시간 갱신을 보장하지 않는다. [Android 공식 위젯 갱신 안내](https://developer.android.com/develop/ui/views/appwidgets/advanced).

화면 이동은 현재 화면의 URL 매개변수를 읽고 사용 후 지워 반복 진입도 처리한다. [Expo Router 공식 URL 매개변수 안내](https://docs.expo.dev/router/reference/url-parameters/).

## 통합 검증 확정 기록 (게시 직전)

- 앱: 타입 검사·전체 린트 통과. 전체 201개 파일, 3,675개 검사 통과.
- 서버: 타입 검사·운영 빌드 통과. 전체 116개 파일, 2,041개 검사 통과. PostgreSQL 관련 18개는 로컬 연결 환경이 없어 미실행이며, PR CI의 실제 PostgreSQL 검사 결과를 별도로 확인한다.
- 금액 링크 재현: 변경 전 1건 실패 → 수정 후 동일 기대값 통과. 최초 진입뿐 아니라 사용자가 토스 탭을 선택한 뒤 다시 위젯을 누르는 흐름 포함.
- 세션 판정 재현: 미국 야간 거래 부적격·거래 정지·기간이 끝난 종목까지 시세 나이만으로 지연이라고 표시하던 새 분기의 결함 1건을 수정하고 같은 검사를 통과했다. 서버가 이미 가진 종목별 거래 세션을 전달하며 추가 조회하지 않는다.
- 계정·서버 변경: 이전 계정에서 받은 자료가 지연된 콜백으로 뒤늦게 표시되는 경계를 보완했다. 자료의 출처를 유지하고 조회·저장·표시 전후 확인한다. 관련 변경 전 10건 실패 → 수정 후 신규 11건 통과. 실제 계정 변경 시험이 아닌 모의 비동기 검사다.
- 위젯 개인 설정: 서버·계정·위젯 ID별로 분리. 표시 손익, 평가액/이름순, 상단 고정, 시장 줄 표시. 손익 토글과 설정 저장이 겹쳐도 최신 부분 변경을 합친다. 저장 실패는 성공으로 표시하지 않는다.
- 최소 크기 110×56dp·글씨 200%에서는 경고를 우선 보존하고 숫자가 들어가지 않으면 앱 확인 안내를 사용한다. 508×223dp·115%에서는 목록 공간을 확보한다. 이는 위젯 렌더 구조를 검사한 결과이며 실제 화면 검사를 대체하지 않는다.
- 시장 위젯은 국내·미국·환율을 우선 배치하고 전체 9개 항목을 스크롤한다. 기존 시장 요약 링크·손익 수익률·접근성 설명을 유지했다.
- 기능 플래그 `widgetClarity`: 서버 기본 켜짐, 앱 기본 꺼짐. 꺼진 경로의 기존 표시·수치 검사를 유지하고 기존 스냅샷을 갱신하지 않았다.
- 기존 위젯 검사 일부는 네이티브 갱신 어댑터 모의 구현을 새 인터페이스에 맞췄다. 예상 수치·표시·개수 등 기존 기대값을 완화하지 않았다. 서버 기존 시장 요약 검사는 준비 단계에서 새 플래그를 끄고 예전 응답 기대값을 보존했다.

## 변경 범위와 남은 확인

배포 직전 문서이므로 배포 완료나 실제 기기 정상으로 해석하지 않는다. 최종 게시·운영 조회·실제 휴대폰 적용·화면 확인은 별도 완료 보고서에 기록한다.

- 네이티브 설정·의존성·DB 구조·분석 모델·프롬프트·자료 수집·생성 단계·알림 권한을 변경하지 않았다.
- 고정 대기·추가 AI 생성·시세 조회를 넣지 않았다. 계정 경계를 안전하게 확인할 수 있도록 완료를 기다릴 수 있는 위젯별 네이티브 갱신 API를 사용했다. 설치 위젯 확인 호출의 실제 기기 비용은 아직 측정하지 않았다.
- 장시간 절전·자동 갱신 주기·제조사별 런처·실제 TalkBack 사용은 미검증이다. 실제 설치된 잔고/시장 위젯 외의 자산/브리핑 위젯은 자동 검사와 코드 검토 근거만 있다.
- 글자 배율 변경 시험을 하는 경우 사용자의 원래 1.15로 복원한다. 개인 정보와 실제 자산 수치는 공개 저장소 검증 자료에 넣지 않는다.

## 실제 휴대폰에서 추가 확인한 표시 보완

첫 개선본 `78ea351`을 휴대폰에 적용해 외부 508×223dp·글자 115% 화면을 직접 확인했다.

1. 시장 위젯의 두 번째 행 숫자가 일부 잘렸다. 조회 시각과 스크롤 안내를 한 줄로 합치고 행 여백을 줄여 기본 크기에서 6개 항목을 온전히 보이게 했다. 글자 크기는 줄이지 않았으며 전체 9개 스크롤을 유지한다.
2. 개별 종목 등락률은 낭독 설명에만 전일 대비가 있었고 화면에서는 기준이 빠졌다. 공통 안내줄에도 ‘종목 전일 대비’를 표시한다.
3. 시장 요약 표시를 켜도 5개 지수가 폭을 넘으면 줄 전체가 숨겨졌다. 폭에 들어가는 완전한 지수 항목부터 표시하고 공간 제약을 설정 화면에서 설명한다.

세 관측을 자동 검사에서 변경 전 실패로 재현했고 관련 262개 검사가 수정 후 통과했다. 최종 보완본의 실제 기기 재확인은 후속 배포 보고서에 기록한다.

첫 배포 실제 확인: 합계→같은 평가 기준 이동과 반복 진입, 손익 전환, 상단 고정, 설정 저장·강제 종료 후 유지, 위젯별 설정 독립, 시장 마지막 3개 항목까지 스크롤. 시험용 설정은 기본 상태로 복원했다. 펼친 화면의 직접 확인은 사용자 동작 응답 대기 상태로 아직 정상 판정하지 않는다.

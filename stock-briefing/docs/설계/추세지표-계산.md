## 1. 이 점수가 무엇이고, 무엇이 아닌가

- **무엇**: 가격과 거래량이 지금 어떤 상태인지(이동평균선 위·아래, 최근 수익 흐름, 단기 과열 여부, 흔들림과 낙폭, 거래량이 오른 날에 몰렸는지)를 정해진 식으로 요약한 값이다. 식·상수·데이터 날짜를 모두 공개하고, 같은 봉이면 누가 언제 계산해도 같은 값이 나온다.
- **아닌 것**: 사용자 요청의 "투자 매력도"가 아니다. 앞으로 오를지 내릴지, 사야 할지 팔아야 할지를 말하지 않는다. 12장 백테스트에서 보듯 이 점수와 이후 수익의 관계는 약하고 기간마다 다르다. 그래서 이름을 "**추세 지표 점수**"로 하고, 문구는 "상승 추세 지표가 강합니다"처럼 **지금 지표의 상태**만 말한다 (11장).
- 가치 지표 점수와의 결합(종합 지표 점수)은 다른 단계에서 정한다. 이 문서의 제안: 두 점수가 모두 있을 때만 종합을 내고, ETF(특히 레버리지)는 종합을 내지 않는다.

## 2. 입력 데이터

### 2.1 종목 일봉
- 경로: 기존 `quotes.getCandles(code, "D", 310)` (토스 웹 → 네이버(한국) → 야후 순서, `CandleCache` 경유). 토스 웹은 한 번에 450개까지라 310개는 한도 안이다. 차트가 이미 800개를 받아 두었으면 캐시에서 잘라 쓴다.
- **끝난 봉만**: `completedCandles(candles, marketContext(...), now)` 를 거친 봉만 쓴다 (정규장 중인 오늘 봉, 20:00 전 한국 통합 봉 제외 — 기존 기술분석과 같은 규칙).
- 가격 기준: **분할 반영, 배당 미반영(가격만)**. 토스 웹 일봉이 분할을 반영하는 것을 확인했다 (ORLY 2025-06 15:1 분할 전 가격이 91달러대로 나옴). 지수도 가격 지수라 기준이 같다.
- 한국 종목: 토스 일봉 종가는 KRX 정규장 종가와 같다(삼성전자 9/15~9/23 대조). 거래량은 KRX+NXT 합계라 네이버(KRX만)보다 크다. 거래량 항목은 **같은 출처 안의 비율**만 쓰므로 괜찮지만, 출처를 바꾸면 거래량 묶음 점수가 달라질 수 있다(삼성전자 42 vs 53). 한 종목은 한 출처로 계산하고 출처 이름을 결과에 적는다.
- 쓰는 봉 수: 계산 시점 t 에서 **최근 300개**만 쓴다(5일 평균을 위해 받는 것은 304개 이상). 더 오래된 봉은 쓰지 않는다 — 출처마다 받을 수 있는 길이가 달라도 같은 점수가 나오게.

### 2.2 비교 지수 (상대강도 M4 에만 씀)
시장 요약(`marketSummaryCalc.ts` 의 `benchmarkOf`)과 같은 규칙으로 정한다. 지수 일봉은 `MarketIndices.chart(code, "D", …)` (네이버, 800개·10분 캐시).

| 종목 | 비교 지수 | 네이버 코드 |
|---|---|---|
| 미국 나스닥 상장 (시세 거래소 NSQ) | 나스닥 종합 | `.IXIC` |
| 미국 뉴욕·아멕스 상장 (NYS·AMX), 미국 ETF 포함 | S&P500 | `.INX` |
| 한국 코스피 상장 | 코스피 | `KOSPI` |
| 한국 코스닥 상장 | 코스닥 | `KOSDAQ` |
| 한국 ETF 중 이름에 '코스닥' | 코스닥 | `KOSDAQ` |
| 한국 상장 해외지수·원자재·통화 ETF (`KR_OVERSEAS_RE`) | 없음 → M4 빠짐, 사유 적음 | — |
| 거래소를 모름 | 없음 → M4 빠짐 | — |
| 레버리지 ETF | **기초자산**의 규칙대로 | — |

- 날짜 맞추기: 종목 봉 날짜 d 에 대해 **d 이하의 가장 가까운 지수 종가**를 쓴다. d 보다 뒤 날짜는 절대 쓰지 않는다(미래 자료 섞임 방지).

### 2.3 기호
- 봉 번호 i = 0 … t (t = 마지막 끝난 봉), 봉 수 n = t + 1
- C_i 종가, O_i 시가, V_i 거래량, B(d) 날짜 d 이하 마지막 지수 종가
- r_i = ln(C_i / C_{i−1}) (일간 로그수익률)
- SMA_k(i) = (C_{i−k+1} + … + C_i) / k (산술평균, `indicators.ts` 의 `sma` 와 같음)

## 4. 공통 식

### 4.1 변동성
```
σ_S = max( 표본표준편차(r_{t−62} … r_t),  0.004 )          # 짧은 창: 최근 63개 수익률 (3개월)
σ_L = max( 표본표준편차(최근 252개 r, 모자라면 있는 만큼), 0.004 )   # 긴 창: 1년
```
- 표본표준편차는 (개수 − 1)로 나눈다. 바닥 0.4%/일(연 약 6.3%)은 변동이 거의 없는 종목에서 z 값이 폭주하지 않게 한다.
- 규칙: **긴 창을 보는 항목은 σ_L, 짧은 창을 보는 항목은 σ_S** 로 나눈다 (5장 표에 항목마다 적음).

### 4.2 랜덤워크 척도 h — "추세 없음"일 때 z 가 표준정규가 되게
로그가격의 선형결합 L = Σ_j a_j · ln C_{t−j} (Σ a_j = 0) 은, 수익률이 서로 독립이고 분산 σ² 인 랜덤워크라면
```
Var(L) = σ² · h,   h = Σ_{k=0}^{J−1} ( Σ_{j=0}^{k} a_j )²
```
이다. 그래서 각 원값을 σ·√h 로 나누면 "추세가 전혀 없을 때" 평균 0·표준편차 약 1인 z 가 된다. SMA 의 로그는 로그의 평균으로 근사한다. 계산한 h:

| 원값 | h | √h |
|---|---|---|
| ln(C_t / SMA200) | (n−1)(2n−1)/(6n), n=200 → **66.17** | 8.13 |
| ln(C_t / SMA50) | **16.17** | 4.02 |
| ln(SMA50 / SMA200) | **37.50** | 6.12 |
| ln(SMA200(t) / SMA200(t−21)) | **2.128** | 1.459 |
| ln(C_{t−21} / C_{t−252}) | **231** | 15.20 |
| ln(C_{t−21} / C_{t−126}) | **105** | 10.25 |
| ln(C_{t−21} / C_{t−63}) | **42** | 6.48 |
| ln(C_t / C_{t−20}) | **20** | 4.47 |

보정 표본(7.2)에서 이렇게 만든 z 의 |z| 90번째 백분위가 1.47~1.78 로, 표준정규의 1.645 와 거의 같았다 → 척도가 맞다.

### 4.3 점수 함수
```
S(x; c)  = 100 / (1 + exp(−x / c))                 # 로지스틱. x=0 → 50점
bell(x; a0, a1, b1, b0) = 0                   (x ≤ a0 또는 x ≥ b0)
                        = 100·(x − a0)/(a1 − a0)  (a0 < x < a1)
                        = 100                     (a1 ≤ x ≤ b1)
                        = 100·(b0 − x)/(b0 − b1)  (b1 < x < b0)
clamp01(y) = min(1, max(0, y))
```

## 5. 항목별 식 (16개)

표의 c 는 로지스틱 폭(7.2 보정값, `TREND-CAL-1`). "묶음 안 비중"의 합은 묶음마다 1.

### 5.1 추세 T (전체 35%)

| 항목 | 원값 | z (x) | 점수 | 묶음 안 비중 | 필요 봉 | 화면 사실값 |
|---|---|---|---|---|---|---|
| T1 200일선과 거리 | ln(C_t / SMA200(t)) | 원값 / (σ_L·√66.17) | S(x; **0.707**) | 0.35 | 200 | "200일선보다 12.8% 위" = e^원값 − 1 |
| T2 50일선과 거리 | ln(C_t / SMA50(t)) | 원값 / (σ_S·√16.17) | S(x; **0.731**) | 0.20 | 50 | "50일선보다 4.2% 위" |
| T3 50일선 vs 200일선 | ln(SMA50(t) / SMA200(t)) | 원값 / (σ_L·√37.50) | S(x; **0.689**) | 0.25 | 200 | "50일선이 200일선보다 8.3% 위" |
| T4 200일선 기울기 | ln(SMA200(t) / SMA200(t−21)) | 원값 / (σ_L·√2.128) | S(x; **0.762**) | 0.20 | 221 | "200일선이 한 달 전보다 2.0% 오름" |

### 5.2 모멘텀 M (전체 35%) — 최근 1개월(21봉)은 뺀다

| 항목 | 원값 | z (x) | 점수 | 비중 | 필요 봉 | 화면 사실값 |
|---|---|---|---|---|---|---|
| M1 12개월(−1개월) | ln(C_{t−21} / C_{t−252}) | 원값 / (σ_L·√231) | S(x; **0.811**) | 0.30 | 253 | "최근 1개월을 뺀 12개월 +18.5%" |
| M2 6개월(−1개월) | ln(C_{t−21} / C_{t−126}) | 원값 / (σ_L·√105) | S(x; **0.702**) | 0.25 | 127 | "6개월 +22.4%" |
| M3 3개월(−1개월) | ln(C_{t−21} / C_{t−63}) | 원값 / (σ_S·√42) | S(x; **0.722**) | 0.15 | 64 | "3개월 …%" |
| M4 지수 대비 상대강도 | 기간 L ∈ {252, 126} 마다 e_L = ln(C_{t−21}/C_{t−L}) − ln(B(d_{t−21})/B(d_{t−L})) | x = 쓸 수 있는 z_L 의 평균, z_L = e_L / (σ_TE·√(L−21)) | S(x; **0.667**) | 0.30 | 127 + 지수 | "같은 12개월 나스닥보다 2.3%p 높음" = (e^{종목} − e^{지수})×100 |

- σ_TE = max(표본표준편차(최근 63개 초과 일간수익 r_i − ln(B(d_i)/B(d_{i−1}))), 0.003). 맞춘 날이 40개 미만이면 M4 없음.
- 최근 1개월을 빼는 까닭: 한 달 수익률은 이후 되돌려지는 경향(단기 반전)이 있어 모멘텀 계산에서 빼는 것이 학계·업계 표준이다(Jegadeesh 1990, Jegadeesh·Titman 1993). 최근 1개월의 움직임은 단기 균형(O) 묶음이 따로 본다.
- 변동성으로 나누는 까닭: 같은 +30% 라도 흔들림이 작은 종목에서 더 뚜렷한 추세다(시계열 모멘텀의 변동성 조정, Moskowitz·Ooi·Pedersen 2012).

### 5.3 단기 균형 O (전체 10%) — 과열·과매도에서 멀수록 높음

| 항목 | 원값 | 점수 | 비중 | 경계 [a0, a1, b1, b0] | 화면 사실값 |
|---|---|---|---|---|---|
| O1 RSI(14) | Wilder RSI(14), 가진 봉 전체로 계산 (`indicators.ts rsi`) | bell | 0.40 | **[20, 40, 65, 85]** | "RSI 55 (중립 구간)" |
| O2 볼린저 %B(20, 2) | (C_t − 하단)/(상단 − 하단), 모표준편차 (`indicators.ts bollinger`) | bell | 0.30 | **[−0.3, 0.2, 0.85, 1.3]** | "밴드 안 위치 65%" |
| O3 50일선 거리(변동성 배수) | ln(C_t/SMA50)/(σ_S·√16.17) | bell | 0.30 | **[−2.5, −1.0, 1.2, 2.6]** | "50일선과의 거리: 평소 흔들림의 1.0배" |

- 경계는 보정 표본 분위수에 맞춘 반올림 값이다 (RSI P1 25.1 · P5 32.9 · P95 72.7 · P99 79.8 / %B P1 −0.16 · P99 1.19 / O3 P1 −2.33 · P99 2.40). 위쪽 평평한 구간을 조금 높게 둔 것은 상승 추세에서 RSI 가 40~80 사이를 오가는 경향(Cardwell·Brown 의 범위 규칙) 때문이다.
- RSI 가 지수 가중 방식이라 시작점에 따라 값이 조금 다르다. 300봉이면 차이는 0.01 미만.

### 5.4 가격 안정성 R (전체 10%) — 흔들림·낙폭이 작을수록 높음

| 항목 | 원값 | 점수 | 비중 | 화면 사실값 |
|---|---|---|---|---|
| R1 변동성 수준 | σ_ann = σ_S·√252 | 100·clamp01( (ln 0.90 − ln σ_ann) / (ln 0.90 − ln 0.15) ) | 0.35 | "최근 3개월 변동성 연 39%" |
| R2 52주 최고 종가 대비 (변동성 배수) | dd = −ln(C_t / max(최근 252개 종가)) | 100·clamp01( 1 − dd / (σ_L·√252) ) | 0.35 | "52주 최고 종가보다 4.5% 아래" |
| R3 1년 최대 낙폭 | MDD = 최근 252개 종가에서 max_i (1 − C_i / 그때까지 최고) | 100·clamp01( 1 − MDD / 0.60 ) | 0.30 | "최근 1년 가장 크게 떨어진 폭 20.2%" |

- R1: 연 15% 이하 100점, 90% 이상 0점, 사이는 로그 직선. 보정 표본 중앙값 27% → 67점, P90 57% → 25점.
- R2 는 종목의 평소 흔들림 대비(연 변동성 1배만큼 떨어져 있으면 0점), R3 는 절대 크기(60% 이상 0점) — 둘을 섞어 "그 종목 기준"과 "누구에게나 같은 기준"을 함께 본다.
- 52주 고점 근처일수록 이후 성과가 나았다는 연구(George·Hwang 2004)가 있으나, 여기서는 예측 근거가 아니라 "지금 고점에서 얼마나 떨어져 있나"를 보여 주는 용도다.

### 5.5 거래량 뒷받침 V (전체 10%)

| 항목 | 원값 | z (x) | 점수 | 비중 | 화면 사실값 |
|---|---|---|---|---|---|
| V1 오른 날/내린 날 거래량 (50일) | U = Σ_{i=t−49..t, C_i > C_{i−1}} V_i, D = Σ_{C_i < C_{i−1}} V_i | x = clip( ln(max(U,ε)/max(D,ε)), −2, 2 ), ε = 1e−9 | S(x; **0.255**) | 0.60 | "오른 날 거래량이 내린 날의 1.11배" |
| V2 거래량 추세 × 가격 방향 | ADV20 = 최근 20개 V 평균, ADV120 = 최근 120개 평균, z20 = ln(C_t/C_{t−20})/(σ_S·√20) | x = ln(ADV20/ADV120) · tanh(z20) | S(x; **0.128**) | 0.40 | "20일 평균 거래량은 120일 평균의 0.82배" |

- V2 의 뜻: 거래가 늘면서 오르면 +, 거래가 늘면서 내리면 −, 거래가 줄면 0 쪽. tanh 로 방향 부호가 경계에서 뒤집히지 않고 부드럽게 바뀐다.
- 거래량의 근거는 다른 묶음보다 약해(Lee·Swaminathan 2000 등 결과가 엇갈림) 비중을 작게 둔다.

## 6. 합치기

### 6.1 묶음 점수
```
묶음 f 의 쓸 수 있는 비중 cov_f = Σ(계산된 항목의 묶음 안 비중)
cov_f ≥ 0.5 이면  F_f = Σ(비중_k · 점수_k) / cov_f   (계산된 항목만)
아니면 그 묶음은 빠짐
```

### 6.2 총점 (그날 점수)
```
묶음 가중치 W = { T: 35, M: 35, O: 10, R: 10, V: 10 }
T 또는 M 이 빠지면 → 판단 불가 ("추세·모멘텀을 만들 기록이 모자람")
쓸 수 있는 가중치 합 ΣW(빠지지 않은 묶음) < 70 → 판단 불가
Score_t = Σ W_f·F_f / ΣW(빠지지 않은 묶음)
coverage = ΣW(빠지지 않은 묶음) / 100   → 화면에 "계산에 쓴 항목 비중 90%" 처럼 (100% 가 아닐 때만)
```
- 봉 200~252개: T4(221 이상부터)·M1·M4 12개월이 빠지고 나머지로 계산하며 "기록 N거래일: 12개월 항목 없이 계산"을 적는다.
- 봉 200~252개이면서 비교 지수도 없으면 M = M2+M3 = 0.40 < 0.5 → 판단 불가 (드문 경우).

### 6.3 화면 점수 = 최근 5거래일 평균
```
표시 점수 = mean( Score_{t}, Score_{t−1}, …, Score_{t−4} 중 계산된 것 )
  · Score_{t−k} 는 봉을 t−k 까지로 자른 뒤(지수도 그 날짜까지) 같은 식으로 계산
  · 오늘(Score_t)이 판단 불가면 전체 판단 불가
묶음 점수·항목 점수도 같은 날들의 평균. 화면의 사실값(%·RSI 등)은 오늘 값
```

### 6.4 반올림과 띠
- 표시: 정수 반올림. **띠는 반올림한 정수로 정한다**(69.6 → 70 → "강함", 글자와 숫자가 어긋나지 않게).

## 9. 레버리지·인버스·특수 상품

### 9.1 분류 (이름·마스터 분류로, 위에서부터)
1. **인버스**: 이름에 `bear`·`short`(채권 낱말 `income|bond|term|duration|maturity|muni|t-bill|floating` 이 같이 있으면 제외)·`ultrashort`·`인버스`·`곱버스`·`숏` → 제외. (`marketSummaryCalc.ts` 의 `isLeverageName` 에서 인버스 부분만 따로 떼어 씀)
2. **레버리지(정방향)**: `isLeverageName` 이 참이고 인버스가 아님 → 기초자산으로 계산.
3. **채권·금리형**: `BOND_ETF_RE` → 제외.
4. 나머지 ETF: 일반 종목처럼 계산 (비교 지수는 2.2 표).

### 9.3 이름으로 찾기 (보조, 목록에 없을 때만)
- 배수: `/(\d(?:\.\d+)?)\s*x\b/i` (예 "2X"). 한국 이름의 '레버리지'는 2.
- 미국 단일종목 상품의 기초 티커: 대문자 그대로 `/\b(?:Long|Bull)\s+([A-Z]{1,5})\b/` → 없으면 `/\b([A-Z]{1,5})\s+(?:Bull|Long)\b/`. 예: "Defiance Daily Target 2X Long RGTI ETF" → RGTI.
- 찾은 티커가 시세 검색에서 확인되지 않으면 "기초자산 확인 불가"로 판단 불가. 한국 상품은 이름 추측을 하지 않는다(정적 목록만).

### 9.4 레버리지 주의 칸 (점수 아님, 사실만)
기초자산 일봉 U, 상품 일봉 E, 배수 L, 모두 끝난 봉 기준.
```
σ_U     = 기초자산 최근 63개 일간 로그수익 표본표준편차 × √252
drag    = (L² − L)/2 × σ_U²                      # 연 로그 손실 (기초자산 제자리·변동성 유지 가정)
변동성 손실(연, %) = (1 − e^{−drag}) × 100
최근 63거래일: 상품 E_t/E_{t−63} − 1,  기초자산 U_t/U_{t−63} − 1,  단순 배수 L × (기초자산 수익률)
상품 자체: 최근 3개월 변동성(연), 최근 1년 최대 낙폭 (R1·R3 와 같은 식, 점수화하지 않음)
```
- 근거: 매일 배수를 다시 맞추는 상품의 로그수익 ≈ L × (기초자산 로그수익) − (L² − L)/2 × σ² × 기간. 변동성이 클수록, 배수가 클수록 기초자산 수익률 × 배수와 멀어진다.
- 상품 자체 봉은 점수에 쓰지 않는다: 3배 상품은 변동성이 늘 매우 커 안정성 묶음이 0 에 붙고, 이동평균·모멘텀도 변동성 손실에 끌려 기초자산 추세와 다르게 나온다.

### 9.5 예시 (2026-09-25 종가, 야후 공개 일봉)

| | SOXL (기초 SOXX, 3배) | RGTX (기초 RGTI, 2배) |
|---|---|---|
| 기초자산 기준 추세 지표 점수 | 73 (강함) | 42 (다소 약함) |
| 기초자산 변동성(연) | 50.7% | 78.5% |
| 계산상 변동성 손실(연) | 53.8% | 46.0% |
| 최근 63거래일 상품 / 기초자산 / 단순 배수 | −29.8% / −2.9% / −8.8% | −36.5% / −9.3% / −18.5% |
| 상품 변동성(연) · 1년 최대 낙폭 | 150% · 69.4% | 155% · 98.4% |

SOXL 은 기초자산이 3개월 동안 −2.9% 였는데 상품은 −29.8% 였다 — "단순 3배(−8.8%)"보다 훨씬 크다. 이 차이를 사용자가 볼 수 있게 하는 것이 주의 칸의 목적이다.

### 9.6 그 밖의 상품
- 일반 지수 ETF(QQQ·SPY 등): 그대로 계산. S&P500 ETF 는 비교 지수와 같이 움직여 M4 가 50 근처로 나오는 것이 정상이다.
- 한국 상장 해외지수 ETF: 원화 가격 그대로 추세를 계산하고 M4 만 뺀다("국내 상장 해외지수 상품이라 코스피 비교를 뺐습니다").
- 분배금이 큰 상품(이름에 `covered call|커버드 콜|option income|premium income|yieldmax|buy-write|프리미엄`): 계산은 하되 "분배금이 큰 상품이라 가격만으로 계산한 추세가 실제 수익보다 낮게 나올 수 있습니다"를 붙인다(일봉이 배당 미반영이므로).

## 10. 최소 기록·갱신 주기·비용

- 최소: 200거래일(200일선). 전체 항목: 253거래일(12개월−1개월). 5일 평균이 모두 차는 것은 257거래일. 요청은 310봉(휴장·정리 여유, 토스 한도 450 안).
- 갱신: 점수는 **끝난 일봉**으로만 바뀌므로 시장마다 하루 한 번.
  - 한국: 20:00(NXT 마감) 뒤 그날 봉이 끝난 봉으로 들어오므로 20:10 이후 새 값.
  - 미국: 뉴욕 16:00 정규장 마감 뒤, 네이버 지수 최종값(17:15 ET) 뒤인 17:30 ET 이후 새 값 (한국 시간 여름 06:30 · 겨울 07:30).
  - 휴장일에는 그대로. 화면에 "9월 25일(금) 미국 정규장 종가 기준"처럼 기준일을 늘 적는다.
- 방식: 조회할 때 계산(lazy) + 결과 캐시. 캐시 열쇠 = (종목, 계산 대상 코드, 마지막 봉 날짜, 지수 마지막 날짜, 버전). 마지막 봉 날짜가 같으면 다시 계산하지 않는다. 선택: 보유 종목만 위 시각에 미리 계산.
- 비용: 종목당 상류 조회 0~2번(일봉 — 차트 캐시가 있으면 0, 지수 — 10분 캐시), 계산 5ms 미만(5일 × 300봉). 모델 호출 0.

## 14. 한계와 열린 질문

1. **비교 지수를 거래소로 정함**: 시장 요약과 같게 했지만, 나스닥 상장 대형주를 나스닥 종합(기술주 비중 큼)과 비교하므로 기술주가 아닌 나스닥 종목은 불리/유리할 수 있다. 대안(모든 미국 종목 S&P500)은 시장 요약과 기준이 달라져 쓰지 않았다. → 결정 필요 시 composite 단계에서.
2. **배당 미반영**: 배당이 큰 종목·ETF는 모멘텀이 실제 총수익보다 낮게 나온다(연 2~4%p, 분배금 큰 상품은 훨씬 큼 → 9.6 안내).
3. **한국 거래량 출처**: 토스(KRX+NXT)와 네이버(KRX)의 거래량이 달라 거래량 묶음이 출처에 따라 10점 안팎 달라질 수 있다. 한 종목은 한 출처로.
4. **5일 평균의 늦음**: 급변한 날에는 표시 점수가 약 2거래일 늦게 따라간다. 그날 값(`scoreToday`)을 상세에 작게 함께 보여 주는 안은 화면 설계 단계에서 결정.
5. **보정 표본의 편향**: 현재 살아 있는 종목, 미국 대형주 중심. 한국 소형주·신규 상장주에서는 c 의 적합도가 떨어질 수 있다. 1년 뒤 재보정 때 한국 표본을 늘린다.
6. **레버리지 목록 관리**: 정적 표에 없는 새 상품은 이름 추측에 기대므로 틀릴 수 있다 → 기초 티커가 시세 검색에서 확인될 때만 쓰고, 등록 시 로그.
7. **지수 휴장과 종목 거래일 차이**: 날짜 맞추기(d 이하 최근 지수값)로 처리. 미국 조기 폐장일은 봉이 있어 문제없다.
8. **요청 문구와의 차이**: 사용자는 "투자 매력도"를 원했다. 이 설계는 의도적으로 "지표 상태"에 머문다. 사용자에게 이 차이를 쉬운 말로 먼저 설명해야 한다(오케스트레이터 몫).

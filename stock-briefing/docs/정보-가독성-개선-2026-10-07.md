# 정보 우선순위·가독성 개선 — 1.5.7

기준: main `2c7c16fc737955d6c6d50f400a1a9a842a3b95a4`, 표시 버전 1.5.6. 이 문서는 구현·판정 기준이며 최종 배포/실기 결과는 작업 PC의 `audit/2026-10-07-information-readability` 보고서에 별도로 기록한다.

## 문제와 합격 기준

### IF-01 잔고 설명이 첫 화면을 차지함 — 사용성 문제, 우선순위 높음

- 근거: 같은 코드 1.5.6의 10월 7일 15:58 외부 화면(475×751dp, 글자 1.15)에서 지수 뒤 계좌 설명이 화면 끝까지 차지하고 보유 종목은 보이지 않았다. 10월 4일 실기 보고서에서도 같은 문제가 관측됐다. 이번 작업 시작 시 휴대폰은 잠겨 있었다. 이 증거를 새 실기 관측으로 부르지 않는다.
- 원인: `TossAccountSummary`에서 평가금액·손익·원본 통화별 금액·환율·원금·계좌 범위·수신 구간·시세 구분 설명을 모두 같은 기본 영역에 배치한다.
- 변경: 대표 평가금액과 손익의 시각적 순서를 유지하며 숫자는 분리해 읽는다. 매입금액·원본 통화·환율·계좌 범위·수신 구간·자세한 설명은 `금액·계산 기준` 한 번으로 펼친다. 비중 버튼은 기본 화면에 남긴다. 시간외 시세 추정은 기준을 펼친 안에서 선택한다. 계좌 원본이 없으면 추정 보기 버튼은 바로 접근 가능하다.
- 항상 표시: 참고 환산/손익, 비용 전후·현금 제외, 계좌 수신 날짜·시각, 추정 원가, 동기화 제외 종목 포함, 실패/지연/원가 누락. 종목 손익과 계좌 손익이 다른 기준임도 목록 전에 표시한다.
- 합격: 기본 화면에서 핵심 금액·경고가 읽히고 보유 목록까지 이동 부담이 줄어든다. 1회 조작으로 전체 기준에 접근 가능. 접기 후 추정 합계가 남지 않고 새 수신 때 펼침 상태가 유지되며 금액은 갱신된다. 큰 글씨에서 숫자·버튼을 자르지 않는다.
- 대가: 원본 통화·원가 설명은 1탭, 시간외 추정은 기본 상태에서 2탭이다. 주 화면의 반복 설명을 줄이는 대신 드물게 확인하는 근거를 한 단계 안에 둔다.

### IF-02 관심종목 차이의 부호 해석 필요 — 혼동을 줄이는 보완, 우선순위 보통

- 코드 근거: 현재가 100/희망가 80에서 `희망가까지 −20 (−20%)`, 현재가 80/희망가 100에서는 `+20 (+25%)`와 희망가 이하 안내가 함께 표시된다. 계산 결함은 아니며 실제 사용자 오해가 발생했다고 단정하지 않는다.
- 변경: 전자는 `20 (20%) 하락하면 희망가`, 후자는 `희망가보다 20 낮음 · 차이 25% (현재가 대비)`로 방향과 분모를 명시한다. 동일 가격은 같다고 표시한다. 지연·가격 시각·통화·알림 상태·편집/상세 버튼은 보존한다.
- 합격: 미도달/도달/동일/시세 없음이 구별되고 원화·달러 및 현재가 분모 계산이 전과 동일하다. 자동 매매나 알림 조건 변경 없음.

## 보호 조건·검사

- `informationFocus` 서버 기본 true, 앱 fallback false. 잔고/관심 화면에서 한 번 읽고 표시 부품에 전달. 끄면 기존 내용과 동작, 기존 스냅샷을 보존한다.
- 기존 계좌·시세 계산과 금액 출처를 사용한다. 수신/시세 시각을 섞지 않는다. 새 API·폴링·고정 대기·재시도·유료 생성 없음.
- 원금/보유·계정 권한·서버 동기화·위젯 갱신·모델/프롬프트/입력·보고서 길이 변경 없음. 생성 결과 품질을 재생성 비교하지 않았으므로 동일 품질을 실험적으로 보증하지 않는다.
- 회귀: 접힘/펼침의 같은 입력 금액, 경고 유지, 실패/오래된 기록, 원화 꺼짐/환율 없음/빈 계좌, 새 데이터/위젯 링크, 기능 끄기, 희망가 방향. 전체 앱/서버 검사와 CI PostgreSQL을 실행한다.
- 새 검사 작성 중 공유 픽스처의 중첩 금액을 수정해 뒤 검사 9건이 실패했다. 기대값을 바꾸지 않고 새 객체를 만들도록 테스트 준비를 수정했다. 제품의 수치 계산을 바꾼 것이 아니다.
- 시각 점검은 실제 기기와 모의 노드 검사를 구분한다. 접근성 속성 검사만으로 TalkBack 실사용 정상이라고 표시하지 않는다.

## 작은 단위 적용 순서

1. 기존 배포·원본/시세 보존 대조 → 잔고 정보 계층 개선.

4. 휴대폰 적용 → 기본/큰 글씨/가능한 폴드 화면·금액 기준 펼치기·목록/상세 왕복 확인. 설정 원복.
